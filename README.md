# Durak Gold — Дурак онлайн (этап 1: игра с другом по ссылке)

Один маленький Node-сервер: раздаёт игру (`public/index.html`) и держит комнаты по WebSocket.
Все правила проверяются на сервере (`engine.js`), рука соперника до клиента не доходит.

## Запуск локально
```
npm install
npm start          # http://localhost:3000
npm test           # движок (2400 партий) + сеть (полные партии, реконнект, сдача)
```
Открой `http://localhost:3000` в двух вкладках: «Играть онлайн» → «Создать комнату» → во второй вкладке
введи код (или открой ссылку `?room=КОД`).

## Выкладка (Render — самый простой путь)
1. Залей папку `durak-online` в новый репозиторий на GitHub.
2. render.com → New → Web Service → выбери репозиторий.
3. Build Command: `npm install`, Start Command: `npm start`, Instance: Free (для теста).
4. Через минуту получишь адрес вида `https://durak-xxxx.onrender.com` — это и есть игра. Ссылки-приглашения
   `…/?room=КОД` работают сразу.

Заметки:
- Free-тариф Render засыпает после ~15 минут без трафика; первое подключение потом занимает 30–60 с.
  Для публичного релиза нужен платный (≈7$/мес) или Fly.io/Railway. Код менять не придётся.
- Сервер хранит комнаты в памяти: при перезапуске активные партии пропадают. Для этапа 1 это нормально.
- Проверка живости: `/healthz`.

## Мобильное приложение (Capacitor)
Приложение будет открывать игру из локальных файлов, поэтому в `public/index.html` нужно прописать адрес
сервера: `const ONLINE_SERVER_URL = 'wss://durak-xxxx.onrender.com';` (сейчас пусто = тот же хост).

## Что внутри
- `engine.js` — правила (подкидной/переводной, 24/36/52), фазы `attack → defend → throwin`, добор, конец игры.
- `server.js` — комнаты, токены переподключения, 60 с на возвращение (потом техническое поражение),
  реванш (проигравший ходит первым), защита: лимит сообщений, размер пакета, валидация карт.
- `public/index.html` — вся игра (офлайн с ботом + онлайн-режим).
